# Daniel Tzul — Developer Portfolio

A personal portfolio website built with React and Vite, showcasing my projects, skills, and experience as a Full Stack Developer.

## Live Demo
https://daniel-tzul-portfolio.vercel.app/

## About
I am a Full Stack Developer graduating from Dallas College in December 2026 with an A.A.S. in Web Development. I build web apps with React on the frontend and Node.js / PostgreSQL on the backend.

- React

## Getting Started

Clone the repo:
```bash
git clone https://github.com/Dtzul04/daniel-tzul-portfolio.git
```

Install dependencies:
```bash
npm install
```

Run locally:
```bash
npm run dev
```
